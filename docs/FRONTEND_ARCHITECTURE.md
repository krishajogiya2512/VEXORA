# Frontend Architecture

- Built with React and styled using Tailwind CSS.
- Desktop integration packaged using Electron.
- State managed through modular React hooks and Context API.
- Dashboard analytics rendered with responsive chart components.

## Component Hierarchy
- `src/components/layout/`: Common sidebar, header, and navigation shells.
- `src/components/dashboard/`: Risk metric cards and real-time activity stream.
- `src/components/detection/`: Profile submission form and results viewer.
